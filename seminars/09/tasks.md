## Задания к семинару №9

**Замечание**: соблюдение во всех заданиях принципа инкапсуляции обязательно. Только необходимые члены класса должны быть публичными. Не должно быть возможности нарушить соласованность внутреннего состояния объекта.

1. Определите абстрактный класс `Animal`. У каждого животного есть возраст, который можно изменять. \
   Определите интерфейсы `Walking`, `Running`, `Jumping`, `Flying`, `Swimming` с методами `void walk()`, `void run()`, `void jump()`, `void fly()`, `void swim()` соответственно. Подумайте, могут ли какие-то из интерфейсов расширять друг друга. \
   Реализуйте классы `Penguin`, `GoldenFish`, `Kangaroo`, `Dog` и `Duck`, отнаследовав их от класса `Animal` и реализовав **правильные** соответствующие интерфейсы. Каждый из методов должен печатать строку, уникальную для каждого действия и животного.
2. Создайте абстрактный класс `Shape` - фигура на плоскости. `Shape` должен хранить центральную точку фигуры. \
   Создайте классы `Circle`, `Rectangle`, `Triangle` и отнаследуйте их от класса `Shape`. \
   В классе `Main` реализуйте метод, позволяющий узнать расстояние между центральными точками двух произвольных фигур.
   В основной программе проверьте вашу реализацию.
3. Создайте абстрактный класс `Sort` - сортировка. Класс должен иметь метод `int[] apply(int[] array)`, реализации которого должны сортировать переданный массив (но не менять исходный). Также каждый класс должен иметь поле типа `String`, хранящее название сортировки. \
   Расширьте данный класс классами `BubbleSort` (сортировка пузырьком) и `InsertionSort` (сортировка вставками).
