## Задания к семинару №8

**Замечание**: соблюдение во всех заданиях принципа инкапсуляции обязательно. Только необходимые члены класса должны быть публичными. Не должно быть возможности нарушить согласованность внутреннего состояния объекта.

1. Создайте интерфейс `Shape` - фигура на плоскости. У каждой фигуры есть периметр и площадь. \
   Создайте классы `Circle`, `Rectangle`, `Triangle` и реализуйте для них интерфейс `Shape`. \
   В классе `Main` создайте методы, позволяющие вычислить суммарный периметр и суммарную площадь всех фигур в массиве.
   В основной программе проверьте вашу реализацию.
2. Для всех классов из предыдущего задания реализуйте методы `toString` и `equals`.
3. Создайте интерфейс `Searchable` с методом `String[] findAllLines(String substring)`. Реализации данного интерфейса должны представлять собой набор строк. При помощи метода `findAllLines` должна быть возможность найти все строки, в которых встречается переданная подстрока.
   1. Создайте класс `Page` и реализуйте в нём интерфейс `Searchable`. Страница должна хранить массив из строк.
   2. Создайте класс `Document` и реализуйте в нём интерфейс `Searchable`. Документ должен хранить массив из страниц.
   3. Создайте класс `Archive` и реализуйте в нём интерфейс `Searchable`. Архив должен хранить массив из документов.
4. Дополните интерфейс `Searchable` из предыдущего задания методами `String findFirstLine(String substring)` и `String findLastLine(String substring)`. \
   Пометьте данные методы `default` и реализуйте при помощи метода `findAllLines`. Если таковой строки не нашлось, возвращайте `null`.
5. Создайте интерфейс `Sort` - сортировка. Интерфейс должен иметь метод `int[] apply(int[] array)`, реализации которого должны сортировать переданный массив (но не менять исходный). \
   Реализуйте данный интерфейс для классов `BubbleSort` (сортировка пузырьком) и `InsertionSort` (сортировка вставками).
